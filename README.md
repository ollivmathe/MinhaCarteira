# Projeto MinhaCarteira - Gestão Financeira Pessoal

## Sobre o Projeto
Este repositório abriga o desenvolvimento completo de um sistema de gestão financeira pessoal, construído como projeto prático para a disciplina de Programação de Sistemas II do curso de Análise e Desenvolvimento de Sistemas da Universidade Presbiteriana Mackenzie. A base de código representa a evolução contínua de uma arquitetura backend, englobando desde os fundamentos de estruturação de dados até mecanismos avançados de persistência e tratamento de erros ao longo de todas as fases da disciplina.
